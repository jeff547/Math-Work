\section*{Definitions}

\emph{Closed Sets}: A set \(S \subseteq \mathbb{R}^n\) is closed if for every convergent sequence
\(\{x_k\} \subseteq S\), its limit lies in \(S\); that is, if \(x_k \to z\) then \(z \in S\).

\vspace{0.2in}

\emph{Open Sets}: A set \(S \subseteq \mathbb{R}^n\) is open if for every point \(x \in S\), there exists
a radius \(r > 0\) such that the open ball \(B_r(x)\) is contained in \(S\); that is, \(B_r(x) \subseteq S\).

\vspace{0.2in}

\emph{Bounded Sets}: A set \(S \subseteq \mathbb{R}^n\) is bounded if there exists \(M > 0\) such that
\(\|x\| \le M\) for all \(x \in S\).

\vspace{0.2in}

\emph{Compact Sets}: A set \(S \subseteq \mathbb{R}^n\) is compact if it is both closed and bounded
(Heine--Borel Theorem).
